# Design: Disable workers.dev on apps/api (Hono)

To prevent public access to sensitive member personal data and accounting details, we are disabling the default public routes generated by Cloudflare (`*.workers.dev`) for `nba-api` and `nba-api-staging`.

## Context & Requirements

- `apps/api` (Hono) is called by `apps/admin` and `apps/storefront` exclusively via service bindings: `env.API_SERVICE.fetch('http://localhost/...')`.
- There is currently no custom domain or custom route bound to `apps/api` in `wrangler.json`.
- The worker has no application authentication.
- Leaving `workers.dev` routing enabled allows public access to the endpoints.

## Proposed Changes

We will modify `apps/api/wrangler.json` to include `"workers_dev": false`:

1. Globally (production environment: `nba-api`)
2. Under the staging environment (`nba-api-staging` environment config)

```json
{
  "name": "nba-api",
  "main": "src/index.ts",
  "compatibility_date": "2024-03-01",
  "workers_dev": false,
  ...
  "env": {
    "staging": {
      "name": "nba-api-staging",
      "workers_dev": false,
      ...
    }
  }
}
```

## Verification Plan

- Verify that the modified `wrangler.json` is syntactically valid JSON.
- Verify that standard vitest unit tests in `apps/api` continue to run and pass.
- Verify using dry-run deployment or configuration checking (if supported) that the setting is accepted.
